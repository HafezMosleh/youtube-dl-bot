## 🌟 Overview
A powerful Telegram bot boilerplate powered by `yt-dlp`. It allows users to send YouTube, Twitter, or Instagram links and receive direct video or audio files right inside their Telegram chat. Highly customizable and scalable.

## ✨ Key Features
- 🎥 **Multi-Platform Support**: Works with YouTube, X (Twitter), and Instagram.
- 🎵 **Audio Extraction**: Easily convert videos to high-quality MP3s.
- ⚡ **Async Processing**: Handles multiple download requests simultaneously.

## 🚀 Getting Started

### Prerequisites
Make sure you have `Python` installed on your local machine.

### Installation
```bash
git clone https://github.com/HafezMosleh/youtube-dl-bot.git
cd youtube-dl-bot
pip install python-telegram-bot yt-dlp
```

### Usage
```bash
python3 main.py
```
