# youtube-dl-bot

A Telegram bot template to download YouTube videos and audios in various qualities.

## Features
- 🚀 Fast and optimized
- 🔒 Secure by default
- 🛠 Easy to configure

## Installation
```bash
git clone https://github.com/HafezMosleh/youtube-dl-bot.git
cd youtube-dl-bot
```
